# Da HoodFarmer — Website v1

This is a static, mobile-responsive brand headquarters site.

## Included
- `index.html` — homepage, SEO metadata, sections and navigation
- `styles.css` — responsive brand styling
- `script.js` — mobile navigation and dynamic copyright year
- `sitemap.xml` — XML sitemap for search engines
- `robots.txt` — crawler access rules and sitemap location

## Deploy with Cloudflare Pages (no paid hosting required for a basic static site)
1. Extract this ZIP on your computer.
2. In Cloudflare, open **Workers & Pages** and create a Pages project.
3. Choose **Upload assets / Direct Upload** (wording may vary).
4. Upload the extracted folder containing `index.html`, `styles.css`, and `script.js`.
5. After the Pages site is live, open the project’s **Custom domains** area and add `dahoodfarmer.com`.
6. Follow Cloudflare’s DNS instructions. Because the domain is registered with Cloudflare, keep the registrar nameservers in place and add the records Cloudflare Pages requests.
7. Also add `www.dahoodfarmer.com` and choose the preferred canonical domain/redirect once both are verified.

Do not change nameservers or DNS records blindly. Keep a copy of the current DNS configuration before making changes.
