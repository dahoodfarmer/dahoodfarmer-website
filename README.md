# Da HoodFarmer — Website Rebuild

Static, responsive brand website for Da HoodFarmer.

## Files
- `index.html` — homepage and SEO metadata
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and copyright year
- `favicon.svg` — site icon
- `robots.txt` and `sitemap.xml` — search engine discovery

## Preview and launch
Upload the contents of this folder to the `site-rebuild-preview` branch of the existing GitHub repository. Cloudflare Pages can then deploy that branch as a preview. Do not change the production branch, Worker, DNS, or custom domain until the preview is reviewed and approved.

## Current business functionality
The site provides brand, venture, media and partnership information. Contact/social actions route to the existing official Linktree. It does not claim to process payments, accept bookings, or collect customer data. Add commerce or lead forms only after the relevant provider, terms and contact details are approved.

## Content review
Review biography and media credit before public launch. Obtain permission for any third-party images, show stills, logos or music before adding them.
